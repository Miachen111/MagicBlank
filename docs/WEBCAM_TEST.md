# Windows 單手指尖測試

在 PowerShell 的專案根目錄執行。測試程式與 `hand_landmarker.task` 均位於根目錄；預設模型路徑依程式位置解析，不受終端機目前目錄影響。

```powershell
cd E:\MagicBlank
.\.venv\Scripts\python.exe .\test_webcam.py --check
.\.venv\Scripts\python.exe .\test_webcam.py
```

`--check` 只載入套件、模型及推論兩幀人工空白影像，不開攝影機。一般模式才開啟攝影機；模型不存在或載入失敗時不開啟攝影機。不必啟用虛擬環境，也不要改用系統的 `python` 代替上述直指定令。

1. 伸入一隻手：觀察 `LOST` 變成 `TRACKING`，食指尖出現綠點。
2. 食指先左右再上下移動：觀察綠點是否跟隨。
3. 整隻手移出再放回：綠點應消失再出現，不沿用舊位置。

點一下攝影機視窗，按 `q`、`Q` 或 Esc 結束；也可關閉視窗。畫面顯示的座標為影像像素，不是桌面座標。本程式沒有深度、觸控判斷或設備控制。

若無法開啟攝影機，確認 Windows 允許桌面應用程式存取相機，並關閉可能占用相機的程式。若有其他攝影機，可自行測試不同編號，例如：

```powershell
.\.venv\Scripts\python.exe .\test_webcam.py --camera-index 1
```

自訂模型可用 `--model 路徑` 指定。模型、影像與虛擬環境不提交 Git。
