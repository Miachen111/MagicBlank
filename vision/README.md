# 視覺模組｜A

目前未實作。先確認相機型號、驅動、左右同步或深度輸出，再選用 SDK。

建議拆成 camera.py、calibration.py、hand_tracker.py、depth.py、touch_detector.py、main.py；先按實際需求建立，不填入假實作。

輸入為相機資料，輸出遵守 shared/PROTOCOL.md。桌面平面與相機使用相同座標系；深度必須與手部追蹤影像對齊。指尖可見表面的深度不等於實際接觸點，須實測補償與門檻。不要以固定深度常數假裝真實觸控。

校正板可作為開發時工具；正式操作區不依賴持續貼附標記。無紋理桌面與指尖邊界可能缺乏有效深度，實測前不保證可行。相機或桌面移動後重新校正。

第一週交付：擷取畫面、追蹤疊圖、接觸與懸空量測紀錄。硬體尚未確認時，可先開發事件輸出介面並使用明確標記的模擬資料。
